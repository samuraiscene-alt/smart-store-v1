# Smart Store V1 Prototype

범용 QR 스마트매장 + 예약 + 최소 관리자 화면 1차 프로토타입입니다.

## 실행
정적 웹서버에서 `index.html`을 엽니다. 관리자 화면은 `admin.html`입니다.

## 이번 버전 포함
- 여성 취향의 밝고 부드러운 고객용 메인 UI
- 관리자에서 서비스 추가/수정/삭제
- 담당자 추가/수정/삭제 및 서비스 연결
- 담당자 선택 ON/OFF 및 명칭 변경
- 날짜/가능시간 선택 바텀시트
- 시간 선택 1차 확인 팝업
- 최종 예약 확인 팝업 필수
- 매장 정기휴무 / 임시휴무 / 담당자 개인휴무
- iPhone `input[type=time]` 기반 휠 시간 선택
- 중복 예약 기본 차단
- 인트로 없음/사진/동영상 선택
- 매장 연락처 vCard 저장
- PWA 기본 파일
